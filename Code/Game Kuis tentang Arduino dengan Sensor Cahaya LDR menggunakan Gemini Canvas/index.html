Buku Saku Materi Arduino LDR

🔌 Inisialisasi & Setup Pin

LED Hijau dipasang pada Pin 11, LED Biru pada Pin 10, dan sensor LDR pada pin analog A0. LDR berfungsi sebagai INPUT untuk mendeteksi perubahan nilai hambatan cahaya.

🔁 Fungsi Setup & Loop

Fungsi setup() berjalan satu kali untuk mendefinisikan pin mode serta menyalakan Serial Monitor dengan kecepatan 9600 Baudrate. Fungsi loop() berjalan berulang kali untuk mengeksekusi logika secara konstan.

🧠 Logika Kondisi Cahaya LDR

Nilai analog yang dibaca berkisar dari 0 sampai 1023. Semakin gelap kondisi sekitar, maka nilai hambatan dan pembacaan analog LDR akan semakin besar.

Kondisi Nilai LDR LED Hijau (11) LED Biru (10)
🌑 Gelap > 600 ON (HIGH) ON (HIGH)
🌗 Remang 301 – 600 ON (HIGH) OFF (LOW)
☀️ Terang ≤ 300 OFF (LOW) OFF (LOW)
